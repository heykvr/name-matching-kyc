# Name Matching Across Identity Documents

Decides whether two name strings (already extracted from POI/POA documents)
refer to the same person. Four matching approaches are implemented and
evaluated against a 148-pair hand-labeled dataset of realistic Indian KYC
name-pair noise.

See `NOTES.md` for the metric justification, results, and final recommendation.

## Layout

```
main_pipeline.py       - orchestrates everything: loads the dataset, runs every
                          algorithm below against it, writes results/
normalize.py            - shared tokenization/cleanup used by every algorithm
algorithms/
  base.py                - shared MatchResult / BaseMatcher
  exact_match.py          - Algorithm 1: exact match after normalization (baseline)
  fuzzy_match.py          - Algorithm 2: Levenshtein-style fuzzy matching (rapidfuzz)
  phonetic_match.py       - Algorithm 3: phonetic matching (NYSIIS)
  hybrid_match.py         - Algorithm 4: domain-tuned hybrid ensemble (recommended)
  __init__.py             - exposes get_all_matchers()
data/
  build_dataset.py       - generates data/name_pairs.csv (148 labeled pairs)
  name_pairs.csv          - the dataset itself
tests/
  test_matchers.py       - unit tests per algorithm + full-dataset integration test
results/                  - generated by main_pipeline.py / pytest (not hand-edited)
```

## Quickstart

```bash
pip install -r requirements.txt
python3 data/build_dataset.py   # (re)generate data/name_pairs.csv
python3 main_pipeline.py        # run all 4 algorithms, print + write results/
pytest -q                       # run the test suite (also re-runs the full eval)
```

Full instructions with exact commands are in `NOTES.md`.
